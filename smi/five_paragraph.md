## 理論五段

**第一段（共識）。** 電腦化測驗記錄了每一題的作答時間，而 van der Linden (2007) 的階層模型把作答正確性與作答時間放進同一個模型，讓作答時間透過能力與速度的相關成為估計能力的附帶資訊（collateral information; van der Linden et al., 2010）。這個做法已延伸到適性測驗的能力估計（Kern et al., 2021）與大型評量的 log 資料分析，而評估其效果的標準一向是精確度：加入作答時間後，能力估計的 RMSE 下降、信度上升（Bolsinova & Tijmstra, 2018）。在本文的模擬中，這個增益也清楚存在：能力的 RMSE 由只用作答資料的 0.44 降到聯合模型的 0.37。

**第二段（機制）。** 附帶資訊的增益來自一個借用管道：模型假設所有受試者共用同一套速度分布與同一組題目時間參數，於是某人作答比預期慢或快，會被解讀成能力高低的訊號，並依能力與時間的關聯強度（γ）流入能力的後驗。這個管道在模型正確時是效率的來源；但它對「為什麼慢」沒有分辨力。只要某個群體因為與能力無關的原因而較慢，這個差異就會沿著同一條管道進入能力估計。我們把這個現象稱為速度洩漏（speed leakage）。在高斯近似下，洩漏量有封閉解 λ(η) = η·1ᵀΩ⁻¹γ / (I_IRT + η·γᵀΩ⁻¹γ)，也就是說，群體的速度差每有一單位，能力差距就被推移 λ 單位。

**第三段（問題）。** 群體之間與能力無關的速度差在實際資料中並不罕見：PISA 的性別差距部分反映作答速度的差異（Kapoor et al., 2024），多語學習者整體作答較慢，且有 7–10% 的題目呈現差異作答時間（Park et al., 2024）。洩漏因此會直接改變群體比較。在模擬中，模型未納入的變數上 0.25–0.5 的速度差使差距偏移 0.07–0.13 SD，95% 區間覆蓋率降到 0.06–0.42；若群體只在少數題目上較慢，偏移可達 0.44 SD，而且連 conditioning 模型已經納入的變數（性別）也偏移 0.2 SD。這與 plausible values 文獻熟知的遺漏變數偏誤不同：後者使差距向零收縮（Monseur & Adams, 2009; Bailey et al., 2023），前者則是加法性的，方向由 γ 決定，而且在題目層次的速度差之下無法靠 conditioning 消除。更關鍵的是，RMSE 與信度在所有這些情況下都仍偏好聯合模型，所以這個錯誤在標準流程中看不見。

**第四段（既有方案的不足）。** 直覺的補救有兩種，但都不夠。第一，把所有與速度有關的變數放進階層模型：這只對估分當時已知、且以人為單位作用的變數有效；次級分析常用的變數在估分時未必存在，題目層次的速度差也不會被人層次的平均數結構吸收。第二，完全切斷作答時間，只用作答資料估計能力，也就是 cut posterior 或 Levy (2024, 2026) 的 measurement-preserving 多階段估計：它保護了能力估計，卻也放棄了全部的精確度增益，而且 Frazier et al. (2025) 已證明在後驗風險意義下，cut 並非最佳。換言之，問題不在「用或不用作答時間」，而在「對某個特定推論，應該讓多少作答時間資訊進入能力估計」。

**第五段（本文框架）。** 本文因此把聯合 RT-IRT 視為兩個模組：受信任的作答模組與可能設定錯誤的作答時間模組，並以半模組推論（semi-modular inference; Carmona & Nicholls, 2020）的影響參數 η 連續地控制作答時間資訊流入能力估計的程度：η = 0 是 cut，η = 1 是完整的聯合模型。這個框架提出三個可檢驗的主張。第一，作答時間模組應在邊際似然上調溫（把 τ 積分掉再乘上 η 次方），才能讓 η 成為平滑的旋鈕，並避免對潛在變數先驗調溫所造成的不當分布。第二，η 應針對每一個推論對象分別選擇，以 conditioning 過的 cut 作為不偏的基準，選擇後驗風險最小者。第三，群體比較幾乎不需要作答時間的精確度（差距的後驗 SD 0.042 對 0.044），因此在釋出分數供次級分析時，群體比較應以只用作答資料的 plausible values 為預設。

## 實作五段

**第一段（模型）。** 作答模組為 probit 2PL：z_ij = a_j θ_i − d_j + e_ij，Y_ij = 1{z_ij > 0}；作答時間模組為 lognormal：log T_ij = ξ_j − τ_i + γ_j θ_i + ε_ij，ε_ij ~ N(0, σ_j²)。能力與作答時間的全部關聯都由 γ_j 承擔，τ 與 θ 獨立，藉此消除剪切方向（shear）的不可辨識性。要報告的群體變數 X 同時進入兩個平均數結構：θ_i ~ N(X_i β_θ, 1)，τ_i ~ N(X_i β_τ, v)，這就是 plausible values 的 conditioning 模型。第一階段的目標分布為 p(Y | φ) · L_RT(φ, ψ)^η · p(φ) p(ψ)，其中 L_RT 是把 τ 積分掉後的邊際似然 N(T_i; ξ − X_iβ_τ + γθ_i, Ω)，Ω = diag(σ²) + v11ᵀ。

**第二段（抽樣器）。** 邊際調溫以一個擴增變數實作：令 τ̃_i ~ N(X_iβ_τ, v/η)，且 T_i | τ̃ ~ N(ξ − τ̃ + γθ_i, diag(σ²)/η)。對 τ̃ 積分後得到 L_i^η · |Ω|^{−(1−η)/2}，所以目標分布只需乘上校正項 |Ω|^{n(1−η)/2}（已用數值積分驗證，`check_marginal_identity.R`）。在此擴增下，z（Albert–Chib 截斷常態）、θ、(a, d)、τ̃、(ξ, γ) 與 β 都有共軛的條件分布；σ_j² 與 v 因帶有校正項，改用對數尺度的單變量 slice sampling。題目鑑別度的混合瓶頸在 z，因此對每題加入 z-scale PX-DA 步驟，使鑑別度 ESS 的中位數提升 56%，額外成本約 12%。η = 0 時略過作答時間模組，得到精確的 cut；若需要第二階段的作答時間參數，巢狀 MCMC 的內層迴圈以 RcppArmadillo 實作，約快 11 倍，且 K = 1 即與參考結果一致。

**第三段（η 的選擇與篩檢）。** 在 η ∈ {0, 0.1, 0.25, 0.5, 0.75, 1} 上各跑一條鏈，對每個推論對象 Δ（群體差距或迴歸斜率）計算 D(η) = Δ̂(η) − Δ̂(0) 與後驗變異數 V(η)，並取 R(η) = D(η)² − V(0) + 2V(η) 的最小值。在 Var(D) ≈ V(0) − V(η) 的近似下，R 是 MSE 的不偏估計。Hausman 型的衝突檢定因為在小 η 時被 Monte Carlo 誤差主導、型一錯誤率偏高而捨棄。另外提供一個只需一次完整擬合的篩檢：把每人的 τ 位置分數 E[(τ_i − m_i)/v | data] 對 conditioning 變數投影後，依候選變數排序累加；在模型正確時，這個過程近似 Brownian bridge，可做 double-max 或二分組的 LM 檢定，用來判斷哪些變數需要跑整組 η。

**第四段（模擬證據）。** 以 n = 500、p = 10、真實性別差距 0.3 SD 的設定，每種情境 50 至 100 份資料。沒有速度差時，風險規則平均選 η ≈ 0.6–0.8，能力 RMSE 為 0.38–0.39，保住大部分增益。有速度差時，不論是人層次（二元或連續、線性或門檻形狀）或題目層次，η 都降到 0–0.13，差距偏誤 ≤ 0.013，覆蓋率 0.88–0.96；完整模型的偏誤則是 0.04–0.44，覆蓋率 0–0.68。篩檢對線性與門檻形狀的速度漂移，檢定力都是 1.00，型一錯誤率 0.00–0.06。選完 η 後的覆蓋率比名目值低約兩個 Monte Carlo 標準誤，論文中應如實報告。另外，利用釋出的速度殘差做事後校正，對人層次的速度差有效，但在題目層次的速度差下失效（偏誤 0.45 → 0.46），因此不列為建議做法。

**第五段（實證示範與使用規則）。** 實證示範以 PISA 2018 的電腦化數學題為例：取同一國家中作答同一題組、有作答時間的學生，性別放進 conditioning 模型，多語背景與 ESCS 作為模型外的比較變數 [DATA: 國家、n、題數、各 η 下的差距估計、風險規則選出的 η、篩檢結果、逐題 DRT 殘差]。由模擬與實證歸納出兩條使用規則。第一，研究者若要以 joint RT-IRT 的分數報告群體比較，應針對該比較用風險規則選 η 並報告所選的值；沒有作答時間資料或比較變數時，以 cut 為預設。第二，測驗計畫釋出分數供次級分析時，群體比較應使用只含作答資料的 plausible values；作答時間的精確度增益只用在個人層次的報告。
